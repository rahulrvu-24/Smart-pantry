# Smart Pantry

A React app for tracking what's in your kitchen, catching food before it expires, and finding recipes that use it up.

Built for CS3301 Full Stack Development (CIE-2 React Mini Project), based on Dave Gray's
[React JS Full Course for Beginners](https://www.youtube.com/watch?v=RVFAyFWO4go).

## Tech stack

- React 19 + Vite
- React Router
- Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev
```
